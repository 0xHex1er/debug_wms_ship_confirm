# Rule: source_code is Read-Only
- โฟลเดอร์ `source_code/` และไฟล์ทั้งหมดที่อยู่ภายใต้โฟลเดอร์นี้ (รวมถึงโฟลเดอร์ย่อย) ถูกกำหนดให้เป็น **Read-Only (อ่านอย่างเดียว)**
- ห้ามทำการแก้ไข (Modify), ลบ (Delete) หรือสร้างไฟล์ใหม่ (Write/Create) ในโฟลเดอร์นี้เด็ดขาด
- AI Agent สามารถทำได้เพียงอ่านและทำความเข้าใจโค้ด (Read only) เพื่อใช้ในการวิเคราะห์หรือเขียนคำอธิบายภายนอกโฟลเดอร์นี้เท่านั้น
